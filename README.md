# منصة استكشاف السعودية والطلعات 🗺️

> **🔗 المعاينة المباشرة:** https://adb707a.github.io/saudi-explorer/

منصة سعودية تفاعلية لاستكشاف المملكة العربية السعودية: مدنها ومناطقها وأماكنها السياحية والمطاعم والمقاهي والأنشطة، مع تخطيط ذكي للطلعات. **الخريطة والكرة الأرضية هما قلب التجربة**، وليستا عنصرًا جانبيًا.

## ✨ أبرز المميزات

- **كرة أرضية ثلاثية الأبعاد** (Three.js + خامات NASA) تبدأ من الفضاء ثم تهبط سينمائيًا إلى السعودية.
- **خريطة تفاعلية** (MapLibre + OpenFreeMap) بحدود المملكة الصحيحة، تحريك/تكبير/تدوير، وانتقالات كاميرا سلسة بين المدن والأماكن.
- **واجهة ORBIT هي الموقع الرسمي** — تجربة واحدة متكاملة تبدأ من الفضاء وتهبط سينمائيًا في خريطة المملكة.
- **نماذج مرجعية إضافية** (للمقارنة الداخلية فقط عبر `#showcase`): المدار، المنظار، الدليل.
- **ثيمات مدن حقيقية**: لكل مدينة هوية بصرية مستوحاة من طبيعتها (بحر/جبل/صحراء/واحة/عمران…) تعمل بالوضعين الفاتح والداكن.
- **مخطّط طلعات**: مدينة/أشخاص/ميزانية/وقت/مدة/فئات → خطة مرتّبة بمسافات وأوقات وبدائل.
- **بيانات موثقة فقط**: لا تقييمات أو أسعار أو ساعات عمل مخترعة، والصور رسوم توضيحية.

## 🛠️ التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 · TypeScript · Vite |
| الكرة الأرضية | Three.js (خامات NASA: Blue Marble) |
| الخرائط | MapLibre GL · OpenFreeMap · تضاريس AWS/Mapzen |
| الطقس / المسارات | Open-Meteo · OSRM (مع بديل تقديري) |
| البيانات | OpenStreetMap (ODbL) · geoBoundaries |
| الأيقونات | lucide-react |

## 🚀 التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173/` — يفتح **ORBIT** مباشرة. للمراجعة الداخلية:

- `#showcase` — النماذج المرجعية القديمة
- `#scope` · `#fieldguide` · `#atlas` · `#pulse` · `#darb` — نماذج بديلة للمقارنة

للبناء الإنتاجي: `npm run build` (الناتج في مجلد `dist/`).

## 📁 مصادر البيانات وتراخيصها

- **الأماكن والمدن**: لقطة من OpenStreetMap (ترخيص ODbL، الإسناد مطلوب).
- **حدود المملكة**: geoBoundaries (ODbL).
- **خامات الأرض**: Solar System Scope (CC BY 4.0) للون والسحب، وNASA لخرائط الإضاءة/الطبيعية.
- **الطقس**: Open-Meteo (مجاني). **المسارات**: OSRM العام (معدل استخدام محدود، مع بديل تقديري).

## 🔐 مفتاح Google Maps (اختياري)

- يقرأ التطبيق `VITE_GOOGLE_MAPS_KEY` من `.env.local` (غير مرفوع) عند البناء. أي قيمة `VITE_*` تُضمَّن في حزمة المتصفح، لذا **المفتاح عام بطبيعته** ولا يمكن حمايته بالسرية.
- قيّده في Google Cloud Console: **HTTP referrers** (localhost ورابط GitHub Pages) و**Maps JavaScript API** فقط.
- التطبيق يتحقق من صيغة المفتاح (`AIza…`، 39 حرفًا) ويرفض تحميله إن كانت غير صحيحة، دون طباعة القيمة.
- تجربة ORBIT الأساسية لا تحتاج المفتاح (تستخدم MapLibre)؛ المفتاح مخصص لفحص `#showcase` فقط، ويُحمَّل كحزمة منفصلة.
- `dist/` و`.env.local` مستثنيان من Git، وبناء GitHub Actions لا يقرأ أي ملف بيئة محلي.

## ⚠️ إخلاء مسؤولية البيانات

المشروع يعرض ما يملكه فعلًا: الاسم، النوع، والإحداثيات. لا يخترع تقييمات أو أسعارًا أو ساعات عمل أو صورًا. أي تكامل مستقبلي (Google Places، مساعد ذكي) يُفعَّل عبر خادم وسيط لحماية المفاتيح.
